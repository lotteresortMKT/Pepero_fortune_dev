# 빼빼로 운세 이벤트

이미지와 스타일, 스크립트를 모두 포함한 모바일 우선 단일 HTML 이벤트 페이지입니다.

## 파일

- `index.html`: 이벤트 페이지. 이미지가 내장되어 별도 이미지 폴더가 필요 없습니다.
- `.gitignore`: macOS 임시 파일 제외 설정.

## 실행

`index.html`을 브라우저로 열면 실행됩니다. 별도 설치나 빌드 과정은 없습니다.

## Git 저장소에 추가

이 폴더 안의 파일을 저장소 루트에 추가해 커밋하세요. 정적 웹 호스팅에서는 `index.html`을 시작 페이지로 사용하면 됩니다.

## 주요 기능

- 제공된 패키지 이미지와 개별 스틱 이미지 사용
- 15개 스틱 중 1개만 위로 뽑히는 애니메이션
- 기존 5종 빼빼로와 15개 운세 결과
- 결과 카드, 다시 뽑기, 가입 안내 팝업
- 가입 페이지 새 창 열기 및 운세 결과 유지
- 모바일 반응형 구성과 동작 줄이기 설정 대응

## 수정

문구와 스타일은 `index.html` 안에서 수정할 수 있습니다. 운세와 추첨 비중은 스크립트의 `fortunes` 항목에서 변경할 수 있습니다.

리워즈 가입 링크: https://www.lottehotel.com/global/en/offline-sign-up?hotelCode=LRBY

## 확인 범위

이미지 내장, 스크립트 문법, 운세 선택, 다시 뽑기, 팝업 상태 전환, 결과 복원 로직을 검사했습니다. 실제 브라우저 화면 검증은 미리보기 도구의 로컬 파일 접근 제한으로 완료하지 못했습니다.
