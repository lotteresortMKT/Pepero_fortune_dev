# 빼빼로 운세 이벤트

승인된 웜 아이보리·초코 브라운·버건디 시안을 반영한 모바일 우선 이벤트 페이지입니다.

## 실행과 업로드

`index.html`을 브라우저로 열면 실행됩니다. 별도 설치, 빌드, 외부 라이브러리가 필요하지 않습니다. 패키지 이미지, 개별 스틱 이미지, 결과 그림, 제목 글꼴이 HTML 안에 모두 포함되어 있습니다.

Git 저장소에는 이 폴더 안의 파일을 추가하세요. 기존 버전을 올렸다면 `index.html`을 새 파일로 교체하면 됩니다. 정적 웹 호스팅의 시작 파일도 `index.html`입니다.

## 파일

- `index.html`: 전체 이벤트 화면과 기능.
- `OFL-Jua.txt`: 내장한 Jua 글꼴의 배포 라이선스.
- `.gitignore`: macOS 임시 파일 제외 설정.

## 반영한 디자인

- 웜 아이보리 `#F7F4EE`, 초코 브라운 `#45332D`, 버건디 `#8B4148`의 공통 색상.
- 둥근 한글 제목체와 은은한 티켓 테두리.
- 메인 패키지가 페이지 맨 아래에서 화면 밖으로 이어지는 배치.
- 뽑기 버튼 아래로 옮긴 유의사항.
- 결과 상단의 운세 분류 라벨과 별도 협업 브랜드 푸터 삭제.
- 오리지널·아몬드·초코필드·화이트쿠키·크런키 각각의 스틱 그림과 옅은 배경색.

## 기능

- 15개 스틱 중 선택된 한 개만 위로 뽑힙니다. 나머지 스틱은 그대로 남습니다.
- 기존 5종 빼빼로의 추첨 비중과 15개 운세를 유지합니다.
- 결과 카드, 다시 뽑기, 가입 안내 팝업과 링크 복사를 제공합니다.
- 가입 페이지는 새 창으로 열립니다. 기존 운세 페이지를 외부 사이트로 이동시키지 않습니다.
- 같은 탭을 새로고침하면 저장된 결과를 복원합니다. 브라우저 저장 기능을 사용할 수 없어도 새 뽑기는 동작합니다.
- 동작 줄이기 설정과 키보드 탐색을 지원합니다.

가입 링크: https://www.lottehotel.com/global/en/offline-sign-up?hotelCode=LRBY

## 문구와 색상 수정

`index.html` 상단의 `:root`에서 공통 색상을 수정할 수 있습니다. `<script>`의 `fortunes`에서 운세와 추첨 비중을, `flavorStyles`에서 맛별 그림 연결과 배경색을 수정할 수 있습니다.

화면 구성은 실제 HTML 요소와 스타일로 작성되어 있으며 이미지 시안을 통째로 붙인 방식이 아닙니다.
